# Header 画面設計書

## 基本情報

| 項目     | 内容                                                             |
| -------- | ---------------------------------------------------------------- |
| 画面 ID  | HDR                                                              |
| 画面名   | 共通ヘッダー                                                     |
| 概要     | ログイン状態にかかわらず、各画面の最上部に常に表示される共通部品 |
| 認証要否 | 不要                                                             |

## 画面部品定義

| No. | ID                 | I/O | オブジェクト種別 | ラベル         | API データ | 説明                                                                         |
| --- | ------------------ | --- | ---------------- | -------------- | ---------- | ---------------------------------------------------------------------------- |
| 1   | app-title          | I/O | リンク           | Kakuta Log     | -          | ホーム画面へのリンク。常時表示する。                                         |
| 2   | output-link        | I/O | リンク           | アウトプット   | -          | アウトプットページへのリンク。                                               |
| 3   | learning-time-link | I/O | リンク           | 学習時間       | -          | 学習時間ページへのリンク。                                                   |
| 4   | task-link          | I/O | リンク           | タスク         | -          | 認証済みの場合のみ表示する。                                                 |
| 5   | theme-btn          | I/O | ボタン           | テーマ切り替え | -          | ライトテーマとダークテーマを切り替える。                                     |
| 6   | login-btn          | I/O | ボタン           | ログイン       | -          | 未認証時のみ表示する。ログアウトボタンと排他表示し、同一位置に配置する。     |
| 7   | logout-btn         | I/O | ボタン           | ログアウト     | -          | 認証済みの場合のみ表示する。ログインボタンと排他表示し、同一位置に配置する。 |
